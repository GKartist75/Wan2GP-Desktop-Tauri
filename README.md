# Wan2GP Desktop Launcher — retired

## Thank you! 🚀

A massive thank you to everyone who downloaded, tested and supported the Wan2GP Desktop Launcher. Building a tool that helped people run Wan2GP locally was an incredible journey — but I no longer have the time to maintain it.

Since **DeepBeepBeep** is the creator and owner of Wan2GP, I asked them to take over or build something even better. They did.

## Use the official WanGP Manager instead

👉 **[Download the official WanGP Manager](https://github.com/deepbeepmeep/WanGP/releases/latest/download/WanGPManager.exe)**

- Made and maintained by **deepbeepmeep**, the author of Wan2GP itself — always up to date with upstream.
- One download, no manual setup.

> [!IMPORTANT]
> **This Tauri Desktop Launcher is no longer updated. Please use the official WanGP Manager from deepbeepmeep himself.**

Thank you all again for being such an awesome community and for all the support along the way!
