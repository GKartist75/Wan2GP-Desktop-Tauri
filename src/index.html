Repair Settings

If saving settings in Wan2GP fails with "Value: N is not in the list of choices: [0, 1]", a saved value is out of range for a dropdown (usually from an older version or imported settings). This scans models/_settings.json and all *_settings.json files and resets out-of-range values to valid ones. Originals are backed up as *.bak-repair.

Share Link

If you see the error "When localhost is not accessible, a shareable link must be created" when launching, that is Gradio's IPv4/IPv6 self-check failing — fix it first with Bind Address → localhost (below) or by adding --server-name localhost to Extra Launch Args. Only if that does not help, enable this to create a public Gradio tunnel (your server becomes reachable from the internet).

Extra Launch Args

Server Port

Port for the Wan2GP web interface. Default: 7860. Changes apply on next launch.

GPU Device

On machines with multiple GPUs (integrated + dedicated, or dual NVIDIA), choose which one runs generation. Passed as --gpu cuda:N on launch. Changes apply on next launch.

Launcher GPU

Which GPU runs the launcher window itself (not generation). Integrated frees 1–5 GB VRAM for generation; Disabled uses SwiftShader. Requires restart.

Desktop Embed (experimental)

How Wan2GP renders in Desktop mode. iframe is the classic embed (downloads land silently in Downloads, then prompt). Applies on next Desktop launch (close the view first).

Debug

Logs [embed] native bounds … to the console whenever the native child webview is repositioned. Off by default — enable only when chasing cut-off or offset embedded-view layout bugs. Takes effect immediately, no restart.

SageAttention wheel

Bind Address

Address Wan2GP binds and connects to. localhost resolves to whatever your PC uses (IPv4 or IPv6) and matches Gradio's own startup check — use it if you saw "When localhost is not accessible…". 127.0.0.1 is a strict-IPv4 fallback for proxy/VPN setups. Changes apply on next launch.

                      Advanced · LAN HTTPS (mic / voice needs trusted HTTPS)
                      

                        

                          
                          
                        

                        

                          
                          
                        

                        

                          
                          
                        

                        

                          
                          
                        

                        
HTTPS is served directly on the Deepy Web port with your cert — open the https:// URL. The cert must cover the exact address your phone opens (IP or hostname); a cert for another name fails with a browser error even when the files are valid. Create LAN cert covers this PC's current LAN IPs automatically. Mic/voice stays blocked on plain HTTP — even over Tailscale/VPN.

                      

                      

                    

                    

                      Advanced · Reverse proxy (RunPod / Nginx / Cloudflare)
                      

                        

                          
                          
                        

                        
Only needed behind a reverse proxy that rewrites the host, or to pin one exact origin (e.g. RunPod https://POD-ID-7860.proxy.runpod.net). Exact origin only — scheme + host + optional port, no /deepy/ path. Leave empty for direct Same-PC / Phone-LAN use. Cannot be combined with the HTTPS redirect port (proxy-managed HTTPS instead).

    •

        Move Wan2GP out of AppData
        
      

      
Your Wan2GP data currently lives in your roaming AppData profile. Move it to a dedicated, fast drive — AppData is meant for small settings, not multi-GB model checkpoints (it can slow logins, trigger antivirus locks, and bloat your profile). Our recommended locations are pre-filled — change any of them if you like.
